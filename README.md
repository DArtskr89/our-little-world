# Наш маленький мир ♡

В этом проекте используются только изображения, которые были присланы пользователем. Никаких сгенерированных изображений в папке assets нет.

## GitHub Pages
1. Распакуйте ZIP.
2. Создайте публичный репозиторий GitHub.
3. Загрузите все файлы из папки `for_him_site` в корень репозитория.
4. Settings → Pages → Deploy from a branch → main / root → Save.

## Аудио
В сайт уже добавлена присланная голосовая запись `voice.m4a`. Она открывается через кнопку «Если хочешь услышать меня».

## Важно
Все изображения и аудио лежат прямо в корне репозитория. Папка `assets` не нужна.
